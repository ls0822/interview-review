## 问题
Java 受检 / 非受检异常？Kotlin 呢？

## 答案
1. 受检：Exception 非 Runtime，必须处理或声明。  
2. 非受检：RuntimeException、Error。  
3. Kotlin **无受检强制**；调 Java 受检方法可不强制 catch，但仍应处理失败。  
4. 给 Java 调用的 Kotlin API 用 `@Throws` 声明。
