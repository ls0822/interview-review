## 问题
自定义注解要写哪些部分？

## 答案
```kotlin
@Target(AnnotationTarget.CLASS, AnnotationTarget.FUNCTION) // 能标在哪
@Retention(AnnotationRetention.RUNTIME) // SOURCE/BINARY/RUNTIME
@Repeatable // 可选
annotation class Route(val path: String)
```

1. **@Target**：类/方法/字段等。  
2. **@Retention**：  
   - SOURCE：仅源码（如 Suppress）  
   - BINARY/CLASS：进 class，运行时不一定反射可见  
   - RUNTIME：反射可读（路由、DI 运行时方案）  
3. 可定义参数（基本类型、String、Class、枚举、嵌套注解等，有限制）。
