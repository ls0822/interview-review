## 问题
Kotlin 相比 Java 最常考的语言特性？

## 答案
**A. 语法特性**

1. 空安全（`?` `?.` `?:`）、平台类型  
2. `data` / `sealed` / `object` / `companion`  
3. 扩展函数、高阶函数与 Lambda、`fun interface`  
4. `inline` / `reified`、委托 `by`  
5. 默认参数、命名参数、`when` 表达式  

**B. 协程特性（单独当成一大章背）**

1. `suspend` / 挂起与恢复  
2. `launch` / `async` / `withContext`  
3. `Dispatcher`（Main/IO/Default）  
4. `Flow` 冷流 vs `StateFlow`/`SharedFlow` 热流  
5. `Channel`、取消与 `Mutex`  

→ 全部展开见《协程与并发》。
