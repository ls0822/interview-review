## 问题
线程池核心参数与坑？

## 答案
1. core / max / keepAlive / queue / handler。  
2. 先填满 core → 入队 → 队列满再建到 max → 拒绝。  
3. **无界队列**可能导致永远到不了 max、任务堆积。  
4. Android 少用 Cached 无线膨胀；可用协程 Dispatcher 或有界池。
