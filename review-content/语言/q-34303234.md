## 问题
`suspend` 为什么 Java 调不了

## 答案
挂起函数编译后会多一个 `Continuation` 参数，用来在挂起之后把结果送回来。Java 没有这套调用约定，直接调用签名对不上。给 Java 客户的 API 保持普通方法：回调、`ListenableFuture`，或你们 SDK 已有的 listener。内部再用协程实现。

`@JvmOverloads` 给 Kotlin 默认参数生成多个 Java 重载。`@JvmStatic` 让 `object` 里的函数在 Java 里变成静态方法。`@Throws` 把 Kotlin 的异常声明成 Java 的受检异常，否则 Java 调用方看不到要捕获。这三件是混编时最常被问的，第 2 天如果还有空再展开其余注解。

## 5. 下午算法

先自己写。卡 25 分钟再看对应的走法。看完盖上，再写一遍。

### 206 反转链表

`1 → 2 → 3 → null` 要变成 `3 → 2 → 1 → null`。手里留三个指针：`prev` 开始是 null，`cur` 开始是头。

每一圈做四件事，顺序不能换：

1. `next = cur.next`，先记住后面还没反转的部分，不然一改指针就丢了。
2. `cur.next = prev`，当前节点指向已经反转好的前半段。
3. `prev = cur`。
4. `cur = next`。

`cur` 变成 null 时，`prev` 就是新头。空链表和只有一个节点，循环不进或只进一次，都成立。

### 141 判环

慢指针每次一步，快指针每次两步。有环就一定会相遇：快的在环里一圈圈追，每步把距离缩短 1。无环时快指针先走到 null。写的时候先判断 `fast != null && fast.next != null`，再走两步，避免空指针。

### 21 合并两个有序链表

建一个哑节点，它的 next 才是真正的新头。这样头结点不用单独讨论。两个指针分别在两条链上，谁的值小就把谁接到结果后面，并前进。一条走完，把另一条剩下的整段接上。最后返回哑节点的 next。

### 19 删除倒数第 N 个

哑节点指向头。快指针先走 n 步。然后快慢一起走，快指针到尾时，慢指针停在待删节点的前一个。`slow.next = slow.next.next`。n 等于长度时，快指针先走就到了尾，慢指针还在哑节点，删掉的是头，所以必须有哑节点。

### 20 有效括号

左括号入栈。右括号时，栈空或者栈顶不是对应的左括号，就是非法。匹配上就把栈顶弹出。扫完栈必须空。`([)]` 这种交叉会在某一次栈顶对不上。

### 155 最小栈

普通栈再配一个最小值栈。入栈时，最小值栈放入「新值和当前最小值中更小的那个」。出栈时两个一起出。取最小值就是看最小值栈的栈顶，O(1)。只在普通栈里存值、每次扫描求最小，就不是这道题要的。
