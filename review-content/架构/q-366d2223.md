## 问题
MVC 是什么？

## 答案
Model 管数据，View 管控件，Controller 管点击和流程。Android 里 Activity 往往又是 Controller 又是 View：`setOnClickListener`、请求、`textView.text = ` 全在里面。

**下一页：**

```text
Activity.onClick
  → page = page + 1
  → 自己把 TextView 改成新页码
  → 自己叫课件容器翻页
```

**举手：**

```text
Activity.onClick
  → 自己发信令
  → 自己 Toast
```

能跑，但 Activity 越来越长。旋转屏幕时，请求回调还拿着旧 Activity，容易泄漏。老代码里常见，新页面很少再这么写。
