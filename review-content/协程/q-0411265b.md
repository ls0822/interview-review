## 问题
Flow 是什么？

## 答案
1. Flow = **异步数据流**：上游 `emit` 发元素，下游 `collect` 收集。  
2. 可组合：`map` / `filter` / `flatMapXxx` / `debounce`…  
3. 默认是 **冷流**（见下题）。

```kotlin
val flow = flow {
    emit(1)
    delay(100)
    emit(2)
}
scope.launch {
    flow.collect { println(it) }  // 开始真正执行上游
}
```
