## 问题
同一条线程上两个协程会交叉跑吗？死循环呢？

## 答案
会交替，但不是操作系统抢占。谁写到挂起点，谁让路。

```kotlin
scope.launch {
    println("1-A")
    delay(100)       // 挂起，工人空出来
    println("1-B")
}
scope.launch {
    println("2-A")
    delay(100)
    println("2-B")
}
// 常见顺序：1-A → 2-A → 之后才是 1-B、2-B
```

把 `delay` 换成一段不挂起的计算，`2-A` 要等整段计算跑完。方法不会「执行一会儿就自动让出」。没有 `yield`、`delay`、`withContext` 这些挂起点，就不会换工单。

循环分两种：

| 循环 | 另一个协程 |
|--|--|
| `while` 里只计算、不挂起 | 同线程上基本跑不到 |
| 每圈有 `yield()` 或 `delay` | 每次挂起都能穿插 |

`yield()` 就是「我先歇一下」。取消也靠挂起点：紧循环里要加 `ensureActive()`，否则 `cancel()` 已经发出，循环还在转。

如果这段死循环跑在 `Dispatchers.Default` 上，并且占满了池里所有工人，别的计算协程也会饿。所以狂算的任务还要限制并行度。
