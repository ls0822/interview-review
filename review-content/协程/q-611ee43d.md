## 问题
`launch`/`async` 里的方法都是挂起函数吗？

## 答案
**A：不是。**

1. `launch` / `async` 的 lambda 是 **suspend 上下文**，块里**可以调用**挂起函数。  
2. 里面你自己写的普通 `fun` **不会**自动变成 `suspend fun`。  
3. 只有声明了 `suspend` 的才是挂起函数；普通代码、普通回调 API 默认都不挂起。  
4. 口述：提供的是可挂起的**执行环境**，不是给所有方法批量加 `suspend`。
