## 问题
怎么限制同时执行数量？

## 答案
1. `Semaphore(许可数)`：最多 N 个同时进。  
2. `Dispatchers.IO.limitedParallelism(n)`：限制并行度。  
3. 固定大小线程池转 Dispatcher。  
4. Channel + 固定个数 worker 协程消费。  

详见下面限流例子：

```kotlin
val gate = Semaphore(3)
repeat(100) {
    scope.launch {
        gate.withPermit {
            download(it) // 最多 3 个同时下载
        }
    }
}
```
