## 问题
`async` / `await` 是什么？

## 答案
1. `async` 启动协程，返回 `Deferred<T>`（一种特殊 Job）。  
2. `await()`：**挂起**等到结果。  
3. 适合同时发起多个请求再汇总：

```kotlin
coroutineScope {
    val a = async(Dispatchers.IO) { api.a() }
    val b = async(Dispatchers.IO) { api.b() }
    use(a.await(), b.await())
}
```

4. 异常：`await` 时才抛出（和 `launch` 不同）。  
5. 要用 `coroutineScope`/`supervisorScope` 管好结构，别火了就不管。
