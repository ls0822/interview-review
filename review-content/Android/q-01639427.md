## 问题
触摸事件分发流程？

## 答案
1. 顺序：**分发 dispatchTouchEvent → 拦截 onInterceptTouchEvent（ViewGroup）→ 处理 onTouchEvent**。  
2. Activity → ViewGroup → … → View。  
3. 某层 `onTouchEvent` 返回 true 消费；否则回传。  
4. `requestDisallowInterceptTouchEvent`：子告诉父别拦截（滑动冲突常用）。
