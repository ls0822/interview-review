## 问题
Activity 生命周期？异常重建？

## 答案
1. `onCreate → onStart → onResume → onPause → onStop → onDestroy`。  
2. 透明主题可能不停到 onStop。  
3. 配置变更默认销毁重建；`ViewModel` + `savedInstanceState`。  
4. 进程杀死后只靠 savedInstanceState 恢复 UI 状态；网络长连接需重连。
