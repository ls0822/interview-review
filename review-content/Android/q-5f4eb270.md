## 问题
Service 启动方式区别？

## 答案
1. **startService / startForegroundService**：独立生命周期，`onStartCommand`；停用 `stopSelf/stopService`。  
2. **bindService**：绑定，`onBind` 返回 Binder；解绑可销毁（无 start 时）。  
3. 可同时 start + bind。  
4. Android 8+ 后台限制：后台起服务受限；前台服务要通知与类型（更高版本更严）。  
5. **IntentService**（已过时思想）→ 用 WorkManager/协程。
